# Lumo 0.7 · 构成研究台

原生 macOS 构成工具。抽象生成从颜色及结构统计生成色块、轮廓和单色线条；新增图像解构直接保留参考像素、纹理与局部形状，分块后重新拼接。所有处理在本机完成。

Lumo is an open-source native macOS tool for abstract compositions, image deconstruction, iterative visual studies, and LineTop-based line extraction. Built with SwiftUI and Metal, all processing runs locally.

**Lumo 以 [MIT 许可证](LICENSE) 开源。** 源码允许使用、修改及分发，完整条件见许可证。公开仓库为 [Vladchen2022/Lumo](https://github.com/Vladchen2022/Lumo)。

## 下载与安装

从 [Releases](https://github.com/Vladchen2022/Lumo/releases) 下载 `Lumo-0.7.1-macOS-arm64.zip`，解压后把 `Lumo.app` 拖进“应用程序”文件夹。要求 macOS 14+ 和 Apple Silicon；Intel Mac 尚未验证。

下载包包含 App、MIT 许可证、安装说明，另提供 SHA-256 校验文件。发布应用使用本机临时签名，尚未进行 Developer ID 签名和 Apple 公证，首次启动可能受 macOS 安全检查限制。兼容性与性能的实测范围见 [VALIDATION.md](VALIDATION.md)。

## 运行与构建

要求 macOS 14+、Apple Silicon 和 Xcode。当前验证机使用 Xcode 自带的 Swift 6.4；源码使用 Swift 5 语言模式。线条提取静态链接仓库内的 arm64 OpenCV core/imgproc 与两个 contrib 算法源文件，无需安装 LineTop、Python 或 OpenCV。第三方许可及源码重建方法见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

```sh
bash Scripts/build-app.sh
open dist/Lumo.app
```

应用位于 `dist/Lumo.app`，可以移到“应用程序”目录。构建脚本使用本机临时签名；本首版供本机试用，尚未进行 Developer ID 签名和公证。

生成包含许可证和安装说明的 App 下载包：

```sh
bash Scripts/export-app.sh
```

下载包与校验文件输出到 `dist/`。本项目不包含用户参考图片、`.lumo` 试用项目或本机测试输出；这些文件留在被 Git 忽略的 `artifacts/` 中。

## 构成研究台

在画布上方点击「研究台」。先在工作副本上试效果，点击「应用到画布」才改变项目，一次 ⌘Z 可撤销。关闭会丢弃本次研究预览。

- **三值明暗、单变量变体**：在黑／灰／白间调整两条分界，检查大明暗；也可保持种子和其他参数，选取六档变体中的一张继续调整。
- **焦点与留白、边缘分级**：先选区域类型，再在预览上拖出矩形。主焦点获得更多块面和对比；留白优先。边缘可分为锐利、柔化和融边，重叠区以后画的标记为准。两项用于抽象生成。
- **配色面积、保明暗换色**：抽象彩色构成可设主色、辅色和点缀色，查看目标与合成后的可见面积估算。暖褐、冷青和冷暗暖亮方案保持相对亮度；高光与暗部会按可用色域降低饱和度。
- **局部取景**：比较不同留白、明暗边界密度及对角趋势的取景，选择后接到现有自由矩形选区。
- **自然肌理、剪影遮罩**：在画布坐标上生成斑驳扩散或矿脉条带。剪影来自用户的透明图片或黑白遮罩，可反相；预览白底，PNG 保留透明区，JPEG 使用白底。
- **限时练习**：选择三值、焦点或冷暖任务，保存参考图并在绘画软件练习。结束后导入习作，并排对照和自查。计时和习作仅在本轮研究台会话中使用。

研究效果和剪影随项目保存。旧项目的画面保持原样；含研究设置的配方使用版本 8，需要 Lumo 0.7+ 打开。

## 试提线稿与透明导出

1. 在当前构成的画布上点「试提线稿」（⇧⌘L），直接提取整张当前画面的边缘。左侧仍可从已有固定阶段提线。
2. 在右侧切换照片／插画，调透明度、对比度、亮度、粗细和细节阈值。点击「返回构成」继续调原画面；满意后点「保存提线阶段」，保留提线输入和可编辑参数。
3. 白底和原图叠加仍可用。导出 PNG 时勾选「透明底（仅线条）」，得到可叠进绘画软件的透明线稿；整图和自由矩形局部都适用。

提线复用 LineTop 的 EdgeDrawing、Zhang–Suen 细化、连通区域去噪和照片／插画预设。预览和导出共享整张输入的遮罩，局部导出不重新检测选区边缘。提线参数后台合并计算；计算完成前保留有效预览并暂缓导出。临时试提不会改变项目配方或新增阶段。

## 项目、收藏与恢复

- ⌘S 后台保存。新版单文件 `.lumo` 将 JSON 参数和去重的图片二进制分开存储，项目上限为 512 MiB，接近上限会提示。旧项目可以直接打开；需要回到 0.5.1 时，请保留升级前的文件。
- 未保存的编辑会在停止操作约 1.5 秒后写入本地恢复草稿。异常退出后从底栏「恢复草稿…」恢复为新项目，原项目不会被覆盖。先处理上次遗留的草稿，之后才继续写入新的草稿。
- 点击收藏可并排比较和改名，确认「恢复此收藏」才替换画面。固定、收藏、删除和改名都可以整次撤销及重做。

## 使用

1. 分别导入颜色和形状参考，或直接从随机构成开始。颜色来源支持三张图片，可以逐层替换，也可以用“导入三张…”批量导入，按文件名顺序放入层 1–3。支持 PNG、JPEG、HEIC、TIFF。
2. 选择颜色层，为该层调整正常、正片叠底、滤色、叠加、柔光及整层透明度。“色块内部混合”控制该层生成的色块如何互相混合，以及色块本身的透明度。眼睛按钮可以隐藏该层。
3. 点击色标或“从参考图点选色标…”，先选择六个色标中的一个，再点击参考图替换颜色。可以放大参考图并单独调节色标权重。每层保留六个可编辑色标；显示的占比是颜色分配概率，实际像素面积会受形状与混合影响。
4. 切换“颜色／形状／组合”。颜色模式不绘制线条；形状模式可切换单色线条和实心块面。
5. 拖动右侧滑块。一次完整拖动对应一步撤销；调回原值可以恢复同一构成。“有机起伏”调整轮廓的鼓起、收缩及大小节奏；“侵蚀细节”增加细小不规则边缘。可从“有机流动”或“侵蚀斑驳”预设开始。
6. 点击右栏底部「随机参数」，在各参数的完整范围内独立抽取新值，包括「高级调节」里的参数。它保留生成方式、参考与种子；图像解构遵循全局／单层范围及单层布局锁。一次 ⌘Z 恢复整组参数。要更换种子，使用左栏「全部随机」；来源锁仍有效。
7. 收藏满意状态，使用 ⌘S 保存 `.lumo` 项目。项目自带参考缩略图、取色预览、提取特征、手动色标、混合参数和收藏，不依赖原图路径。相同图片数据只保存一份。
8. 点击顶部“框选局部”，直接拖动建立任意长宽比的矩形。框内拖动移动选区，四条边均可独立拖动，角点可同时改变宽高；“重新框选”清空选区后重新画。点击“导出选区”选择长边及格式，宽高按选区实际比例自动计算。按 Esc、点击“退出框选”、取消导出面板或导出成功后均回到普通编辑。打开项目时默认进入普通编辑。

整张导出保持画布比例；局部导出保持自由选区的比例。长边预设 1024、2048、4096，也可输入 1–4096 的自定义长边；短边按比例取整到整数像素，选区不受输出尺寸约束。PNG、JPEG 均嵌入 sRGB 配置，单边上限 4096 像素。局部按场景重新绘制，画面中的几何、软边和线宽随同一视区一起放大。

取色优先使用当前导入的原图像素；项目重开或原文件不可用时，使用项目内最长 2048 像素的取色预览。0.1 项目只含原来的缩略图，若需要更细的取色精度，重新导入该参考。所有取样统一转换到 sRGB，透明位置不作为色标。

快捷键：⌘N 新建、⌘O 打开、⌘S 保存、⇧⌘S 另存、⌘Z 撤销、⇧⌘Z 重做、⌘R 随机、⌘D 收藏、⇧⌘F 固定当前效果、⇧⌘L 抽取线条、⇧⌘E 导出。

## 固定当前效果

点击顶部“固定当前效果”，确认这一轮结果后继续处理。固定针对整张画布，不受选区和导出尺寸影响。完成后左侧显示本轮输入，下方“阶段与收藏”自动保留固定前的参数和来源；⌘Z 可撤销整次固定，保存项目后也能从阶段记录恢复。固定期间暂停编辑，失败不替换画面。

- **图像解构**：将所有可见图层及混合效果合成一张长边 4096 像素的 sRGB PNG，作为下一轮的整张输入。打散归零，画面保持原来的效果；再拖动打散，就会切分、重新拼接这张合成图。再次固定可继续第三轮处理。
- **抽象生成**：保留当前几何、布局、层间混合与色彩，不重新随机构图。色彩与结构控制回到本轮中性值 50，色相和方向回到 0；表现参数保留原值。之后的变化叠加在已经固定的形状上，再次固定建立下一个起点。
- “恢复本轮起点”回到本次固定时的画面，可以重新尝试；导入新图片或应用起始预设会结束当前阶段，旧结果仍可从阶段记录恢复。

解构的多轮处理会反复采样像素，细节可能逐轮损失；固定不增加新的源图细节。抽象生成保留可编辑几何，单阶段最多 768 个形状。阶段与收藏合计最多 100 个，项目上限 512 MiB；固定前先校验完整项目能否保存，超限时保留当前状态并提示。

## 图像解构

在右侧“生成方式”选择“图像解构”，使用左侧一至三张颜色来源的原图。每张图片以固定种子分成 8–80 个不规则多边形，保留全部源图区域及碎片内部像素。打散为零时按原比例完整重建每张图片，按层间设置叠合；有留白时来自图片与画布的比例差异。

- 分块数量改变局部切分边界；每个分块位置有稳定编号，往返参数可恢复。
- 打散程度使用更灵敏的连续位移曲线，20% 打散已完成约 45% 的位置重组；成组移动的目标分布覆盖画布，保留组内关系时仍能明显错位。旋转幅度为 0–360°，每个碎片按固定随机系数选择顺／逆时针角度，成组保留会混合组内方向；这是最大幅度，不是所有碎片一起转同一角度。
- 大小差异使用连续指数缩放。拉满可在原碎片线性尺寸的 0.05× 到 5× 之间形成层次，理论缩放极差为 100:1，并增加接近两端的碎片数量。实际尺寸还受原始分块大小影响。
- 整体缩放控制所有碎片的共同尺寸：最左 0.12×、中点 1×、最右 4×。达到 20% 打散即使用完整范围，不再乘以打散值压小变化；与大小差异相乘，可产生很小的点缀及覆盖大片画面的主块。
- 「碎片间距」只聚拢或拉开位置，保持单块尺寸；旋转、大小和间距在打散 0–20% 时平滑启用。「还原原图布局」将各层打散归零并清除手动碎片编辑，可撤销。
- 旧解构项目和收藏先按原算法恢复画面；拖动打散／大小差异／间隙、点击“启用更强变化”或重置此组时启用新范围，升级与完整拖动均可撤销。新建构成默认启用。新范围使用版本 6 配方，需要 Lumo 0.5.1+；回退请打开升级前保留的旧项目。
- 局部关系保留让相邻碎片共同移动与旋转。保留为 100%、大小差异为零、间隙／重叠为 50% 时，同组碎片保持刚性局部关系。
- 碎片边缘参数与抽象生成的软边参数独立。切换生成方式保留两套控制状态；色标与形状参考仍只参与抽象生成。
- 三张图分别分块后叠合，可沿用层间混合、碎片内部混合、两级透明度和隐藏层。“重新分块”使用结构种子；“换叠放”只更换碎片覆盖次序，保留分块与几何。
- 点画布上方「编辑碎片」，点选或拖动一块，再用工具栏隐藏或锁定。锁定会保住当前位置和轮廓。改变分块数量、重新分块或切换裂边会清除受影响层的手动编辑；可撤销。
- 选择来源层后，在右侧切到「第 N 层」独立调整。可锁住该层分块、位置及层内叠放。左侧拖动图层手柄或用上下移菜单改变层间顺序，原来的分块保持不变。
- 「有机裂边」让相邻碎片使用共享的折曲边界，打散归零时仍能无缝拼合。此模式不按参考图中的物体轮廓分割。
- 使用画布上的放大按钮后，可在画布区滚动平移；局部选框使用原画布坐标，与缩放倍率无关。

目前的直边与有机裂边模式均不沿原图的颜色、锈斑或石纹分割。原图中的具象内容可能保留。旧项目使用最长 2048 像素的取色预览，缺少预览时使用缩略图；重新导入会保存最长 4096 像素、最多 32 MB 的 sRGB PNG，超出大小限制时沿用取色预览。局部放大受这些像素分辨率限制，不增加细节。整个项目上限为 512 MiB。

## 实现

- `LumoCore`：可编码配方、独立种子、抽象场景、参考分析、项目校验、Metal 渲染和 ImageIO 导出。
- `Lumo`：SwiftUI 界面、按需绘制的 MTKView、滑块撤销事务、收藏和文件面板。
- 抽象生成仅消费代表色与占比、结构方向、曲直、区域尺度和疏密统计。图像解构另设 Voronoi 分块场景和 Metal 纹理管线，直接读取项目内参考像素。
- 画布和导出共用 Metal 管线，普通透明合成在 sRGB 线性空间进行；叠加、柔光等混合公式在 sRGB 编码值上计算，再转换回线性工作空间。程序化混合使用 Apple GPU 的 [Metal 可编程混合](https://developer.apple.com/documentation/Metal/rendering-a-scene-with-deferred-lighting-in-objective-c)。
- 0.6 使用 LUMO3BIN 文件容器，仍可读取旧 JSON 项目并保持来源、种子及原有参数。碎片编辑、图层布局、间距与裂边用版本 7 配方。缺少生成方式时默认抽象生成；旧解构配方使用版本 2，需要 Lumo 0.3；扩展变换配方使用版本 3，需要 Lumo 0.3.1；固定阶段使用版本 4，需要 Lumo 0.4。阶段不递归嵌套配方，相同图片数据继续去重。未知版本或无效数据不会替换当前画面。

## 验证

```sh
swift test
bash Scripts/build-app.sh
dist/Lumo.app/Contents/MacOS/Lumo --verify
dist/Lumo.app/Contents/MacOS/Lumo --verify-deconstruction artifacts/verification/workflow.lumo
```

`--verify` 在 `artifacts/verification` 生成测试参考、项目、模式示例、2048×1536 局部 PNG、4096×4096 JPEG 和 `report.json`。它执行三张颜色参考和形状参考导入、原图取色、有机调节、分层混合、锁定、收藏、删除原图后的项目恢复、带色彩配置导出，并测量 1536 像素、最大密度组合模式的渲染耗时。

性能报告测量场景生成、提交和等待 GPU 完成的耗时，不包含窗口系统或 SwiftUI 事件调度。实际窗口的操作检查与帧间隔测量见 `VALIDATION.md`。

0.3.1 解构验证在 `artifacts/deconstruction-range` 生成三层试验项目、零打散重建、多层解构、1024×768 裁切、4096 像素 JPEG 及 `report.json`。实际窗口性能可通过 `--profile-window <report-path> --profile-project <project-path>` 测量；正常启动不会运行性能脚本。
